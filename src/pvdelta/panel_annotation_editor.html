Native panel reference editor

Draw every complete module with four ordered corners. Use Ignore for partial or ambiguous areas. No predictions are supplied. Zoom changes display size only; saved coordinates remain on the native grid.

Click four corners around a module. Click a corner to select and drag it. Selected shape is yellow; modules cyan; ignore areas magenta. On a phone, use the scrollbars to move the zoomed image. Undo/delete and editing always invalidate completion.
